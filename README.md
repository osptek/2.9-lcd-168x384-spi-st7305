# 2.9 寸 168×384 全反射 SPI 模组（ST7305）资料与示例

> 本仓库提供该模组的 **示例工程**，以及数据手册、规格与接口说明等资料，便于选型参考与集成开发。

## 产品概要

| 项目 | 说明 |
|:--|:--|
| 模组规格 | 2.9 英寸 **全反射式 LCD**（黑白），分辨率 **168×384** |
| 接口 | **SPI** |
| 驱动芯片 | **ST7305** |
| 规格标识 | 产品资料中常用 **`2.9-lcd-168x384-spi-st7305`** 表示本规格 |
